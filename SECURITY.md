# Security policy

Version 1.0.x is supported while it is the current release line. Report a
suspected vulnerability privately through the security contact configured on
the Tahr Security GitHub organization; do not open a public issue containing
sensitive details or reporter data.

Include affected version, impact, reproduction conditions, and suggested
mitigation without real credentials or personal information. Maintainers will
acknowledge, validate, coordinate remediation, and publish disclosure guidance.

Never commit secrets. Rotate any value suspected of exposure and invalidate
affected sessions. Provider acceptance testing, publication, package visibility,
deployment-catalog changes, and deployment require explicit operator approval.
